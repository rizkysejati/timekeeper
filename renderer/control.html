Timekeeper V5

Output (layar penonton)

Aktif saat output terbuka. Di jendela output: klik dua kali / F11 = layar penuh, Esc = keluar.

Rundown & lembur

Rundown diatur di kartu tiap timer. Pindah otomatis hanya berlaku bila Lembur dimatikan. Saat Lembur aktif, pindah segmen manual (tombol Berikutnya atau tombol N).

Peringatan warna

Di atas tahap 1, warna timer mengikuti "Warna teks". Mau hijau di awal? Set warna teks jadi hijau.

Alarm saat waktu habis

Alarm berbunyi lewat jendela kontrol ini (komputer operator). Format: mp3, wav, ogg, m4a, aac, flac (maks 15 MB). Filenya disalin ke penyimpanan aplikasi.

Server lokal (OBS Browser Source & remote HP)

Remote HP: buka alamat ini di HP (harus satu WiFi dengan komputer), lalu masukkan PIN.

PIN:

OBS: tambah sumber Browser, tempel URL di atas, atur lebar/tinggi sesuai kanvas, lalu hapus centang "Shutdown source when not visible" bila perlu. Latar transparan juga bekerja di sini. Server ini hanya menerima perintah Mulai/Jeda/Reset/Atur waktu/Segmen, bukan pengaturan aplikasi.

Hotkey

Klik tombol pintasan lalu tekan tombol baru. Esc batal, Backspace atau Delete mengosongkan. Hotkey global hanya untuk pintasan dengan Ctrl/Alt/Shift atau tombol F1-F24; tombol biasa (spasi, huruf, angka) hanya jalan saat jendela ini aktif.
